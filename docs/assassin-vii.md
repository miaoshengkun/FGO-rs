# 冠位钻研战[暗匿者]VII

GUI 任务模式选择「冠位钻研战[暗匿者]VII」。任务绑定 `profiles/assassin-v1.json` 与 `scripts/assassin_farm.rhai`，使用 CN 界面。前排必须为 1 光之高扬斯卡娅、2 助战河上彦斋（120 级）、3 斯忒诺；御主礼装需提供本阵容使用的 1、2 技能。当前队伍由玩家预先配置。

助战选择校验同一行的河上彦斋名称、完整 120/120 等级与好友标记，编队再次核对第 2 位等级，开战核对三位角色、助战位置及等级。模板来自 MuMu 1920×1080 实机，归一化为 1280×720。未知身份或未校准的战斗立绘会停止。

首回合顺序：

1. 助战技能 1、2、3。
2. 光之高扬斯卡娅技能 1、2、3；需要友方目标时均选择第 2 位。
3. 再次释放助战技能 2，必须已恢复冷却。
4. 斯忒诺技能 1、2、3。
5. 御主技能 1、2，需要友方目标时选择第 2 位。
6. 斯忒诺宝具 → 河上彦斋宝具 → 助战普通卡。两张指定宝具均须可用，光之高扬斯卡娅宝具不参与首回合选卡。

普通卡严格优先助战，再按红→蓝→绿选择与出牌；没有助战卡时按相同颜色顺序补牌。暴击、克制和连携评分不会覆盖该顺序。

未结束时自动检查前排 2、1、3 位的可用技能，再按斯忒诺→助战→光之高扬斯卡娅顺序使用可用宝具，剩余位置仍优先助战红→蓝→绿。冷却和禁用技能跳过，未知状态停止；最多 100 回合。该接管沿用现有技能状态识别，不推断技能效果或复杂时机。

可从当前关卡列表、助战、编队、连续出击提示或尚未操作的首回合启动。脚本不会在已操作的首回合自动重复整套技能。场次、苹果与时长沿用 GUI 预算，默认 1 场、0 苹果，总时限 0（不限）。场次设为 0 时持续周回，直到体力不足且苹果额度用尽；单个动作的识别与验证超时仍然生效。

首次使用先同步三位从者的 Atlas 数据：

```sh
cargo run --locked -- sync-data --profile profiles/assassin-v1.json
cargo run --locked --features maa -- \
  --maa-library .tools/maa/sdk/bin/libMaaFramework.dylib \
  --maa-ocr-model ../MaaFgo/assets/resource/base/model/OCR \
  run scripts/assassin_farm.rhai --profile profiles/assassin-v1.json \
  --serial 127.0.0.1:16384 --execute --battles 1 --apples 0 \
  --max-seconds 0 --trace logs/assassin-run.jsonl
```

`attack_nps([3, 2], true)` 指定本次允许且必需的宝具槽位，出牌顺序由 Profile 的 `noble_phantasm_order` 控制。`face_card_color_order` 是可选的严格选卡策略，现有骑阶与剑阶 Profile 不启用，保持原评分行为。
